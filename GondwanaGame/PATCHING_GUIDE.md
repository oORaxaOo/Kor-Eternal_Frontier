# KOR-ETERNAL FRONTIER — Beginner Patching Guide

You can change the starter scenario's main balance values without editing C#.

## Project files

- `Program.cs` starts SDL3, Gondwana, input polling, and the fixed-step update loop.
- `Simulation/OutpostSimulation.cs` contains the worker, economy, construction, objective, and Blight rules.
- `Simulation/ScenarioBalance.cs` validates editable balance values.
- `Rendering/OutpostRenderer.cs` draws the map and interface. Drawing code does not control the simulation.
- `Data/Balance/scenario.json` contains the starter scenario's editable costs, rates, and starting resources.
- `Tests/ScenarioChecks.cs` contains dependency-free gameplay checks invoked by `--self-test`.
- `artifacts/linux-x64/` is generated by the Linux packaging script and is excluded from Git.

## Change balance values

Open `Data/Balance/scenario.json` in a text editor. Keep the JSON commas and quotation marks intact.

For example, to start with more alloy and reduce purifier cost, change:

```json
"startingAlloy": 140,
"purifierAlloyCost": 80
```

to:

```json
"startingAlloy": 220,
"purifierAlloyCost": 65
```

Other useful values:

- `startingSupplies`, `suppliesPerGather`: supply economy.
- `alloyPerGather`: alloy gained at the western salvage deposit.
- `workerSpeed`: worker movement in tiles per second.
- `workIntervalSeconds`: time between gathering and construction work.
- `purifierSuppliesCost`, `purifierWorkPerInterval`: purifier construction.
- `blightSpreadSeconds`, `blightSpreadSkipEvery`: Blight spread cadence and density.
- `purifierRange`: how far completed purifiers cleanse.
- `shelterDamagePerSecond`: damage while the command shelter is infected.

The game checks values at startup and explains invalid values. Restore the original scenario values by reversing only your intended JSON edits in your text editor.

Starting map dimensions, fixed deposit and rock locations, the objective, and visual colors are currently defined in C# (`OutpostSimulation.cs` and `OutpostRenderer.cs`). The current wireframe palette is declared near the top of `Rendering/OutpostRenderer.cs`:

- `Charcoal`: background.
- `Crimson` and `KorWire`: Kor accent and structural outlines.
- `TerrainWire`: terrain tile outlines.
- `Gold`: selection and important feedback.
- `BlightWire`: Blight creature contours.
- `PanelEdge`: interface panel borders.

Change one value at a time, build the project, and inspect it at the normal gameplay zoom. Many secondary highlight colors are still local to drawing methods and have not yet been moved into a separate art configuration file.

There is no technology tree yet; adding technologies requires a future gameplay implementation, not a balance-file entry.

## Build, test, and package

Install the .NET 8 SDK and SDL3 on NyarchLinux/Arch Linux. From this folder:

```sh
dotnet build GondwanaGame.csproj --configuration Release
dotnet run --project GondwanaGame.csproj --configuration Release -- --self-test
./build-linux.sh
./launch-kor.sh
```

The self-test does not need a window. The published executable and its native Skia file are placed under `artifacts/linux-x64/`. `launch-kor.sh` can be double-clicked in many file managers after marking scripts executable, or launched from a terminal.

## Recover from a broken edit

Before editing, make a copy of the file you plan to change. If you use Git and want to discard only your own edits to one tracked file, review them first with `git diff -- path/to/file`, then use `git restore -- path/to/file`. Do not run that command on files containing someone else's changes. To get back to the last packaged state, rerun `./build-linux.sh` after the build succeeds.

If the game exits, start it from a terminal so the error is visible. Configuration errors name the JSON path; SDL startup errors describe the missing video/runtime dependency. The game does not currently write a persistent log file.

## Asking an AI assistant for a focused patch

Name one feature and its file boundary. For example: “In `Simulation/OutpostSimulation.cs`, increase the worker's gather rate using the existing `Data/Balance/scenario.json` setting. Preserve the other gameplay rules, run the Release build and `--self-test`, and report the files changed.” Ask for a focused diff and verification rather than a rewrite of the whole project.
