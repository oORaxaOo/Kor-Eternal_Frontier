# Higgsfield asset prompts

Use one prompt per generation. These are original Kor-Eternal Frontier assets. The user's RTS screenshot is only a broad reference for battlefield scale and information density; do not copy any logo, symbol, text, unit, building, or exact composition from it. The Kor character image is only a visual identity reference for Lilith, not a battlefield unit reference.

## 1. Battlefield style anchor

**Use case:** stylized-concept  
**Asset type:** 16:9 real-time strategy battlefield background plate  
**Prompt:** Create an original, premium pre-rendered RTS battlefield environment for Kor-Eternal Frontier, viewed from a consistent elevated three-quarter/isometric game camera. A harsh frontier valley at late afternoon: layered dusty earth and gravel, a winding compacted vehicle road, shell-scarred concrete, scattered wreckage, scrub vegetation, distant industrial Kor settlement structures, atmospheric dust and restrained smoke. The Kor are an original cooperative industrial civilization: weathered graphite and steel infrastructure, deep crimson cloth/markings, restrained amber lamps. Keep the central playable ground readable and relatively open for units; place richer environment detail toward the edges and horizon. Natural cinematic light from upper left, clear contact shadows, rich material detail, coherent scale, high-detail hand-art-directed real-time strategy game environment, crisp readable ground texture. 2560×1440 composition.  
**Avoid:** any logos, insignia, lettering, interface, people, soldiers, vehicles, copied game assets, SCP material, photorealistic camera blur, excessive bloom, flat vector illustration, toy appearance, busy center, watermarks.

## Selection process

Generate one style-anchor environment first and review it before generating the sprite set. If it passes, use the same camera and lighting instructions verbatim for the tank, Guardian, habitat, and Blight. Select one result per asset, retain the original full-resolution file, then inspect alpha and pivots before importing into the game. Do not accept text artifacts or use a generated sheet as multiple sprites.
